## 🕹️ Descripción del Proyecto

Este proyecto consiste en un sitio web interactivo y adaptativo desarrollado como parte del proceso formativo. Incluye catálogo de productos, carrito de compras, sección de noticias (blog), formulario de registro con validaciones dinámicas y páginas informativas.

---

## ✨ Características Principales

- **Navegación Intuitiva**: Estructura limpia y fácil de navegar entre secciones.
- **Formulario de Registro**: Validación de campos en tiempo real mediante JavaScript.
- **Sección de Blog & Noticias**: Múltiples artículos enfocados en el mundo gamer.
- **Catálogo & Carrito**: Vista detallada de productos y gestión de compras.
- **Contenido Multimedia**: Inclusión de videos e imágenes optimizadas para la experiencia del usuario.
